# Knowledge Base

This folder is the curated source for RAG. Only place high-signal, stable
references here. Keep files concise and scoped to a single topic.

Recommended content:

- Protocol summaries per reaction family (with ranges and caveats).
- Rule rationale and applicability notes.
- HTE statistics and common failure modes.
- Reagent alias notes, compatibility, and safety.
- Mechanistic quick guides and troubleshooting checklists.

Formatting tips:

- One topic per file.
- Use clear headings.
- Add a short metadata header block at the top:
  - id: Reaction family ID
  - title: Canonical name
  - tags: Comma-separated tags
  - scope: Short substrate/reaction scope
  - source: Document/source reference
- Prefer tables or bullet lists for conditions.

See `TEMPLATE.md` for a starting point.
