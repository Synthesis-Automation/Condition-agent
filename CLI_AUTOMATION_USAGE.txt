"""
Quick Reference: Using the Interactive CLI with Automation Format
==================================================================

FILTERING BY SOURCE TYPE (Rule vs Protocol)
-------------------------------------------

Option 1: Interactive Mode
---------------------------
python app/unified_rule_protocol_interactive_cli.py

# Inside the interactive prompt:
/type rule              # Show only rules
/type protocol          # Show only protocols  
/type all               # Show both (default)

# Example workflow - Rules only with automation:
reaction> /automation on
reaction> /scale 2.0
reaction> /type rule
reaction> CCBr.c1ccccc1B(O)O>>CCc1ccccc1


Option 2: Command-Line Mode
----------------------------
# Only rules:
python app/unified_rule_protocol_interactive_cli.py \
    --rxn "CCBr.c1ccccc1B(O)O>>CCc1ccccc1" \
    --type rule \
    -k 3

# Only protocols:
python app/unified_rule_protocol_interactive_cli.py \
    --rxn "CCBr.c1ccccc1B(O)O>>CCc1ccccc1" \
    --type protocol \
    -k 3

# With automation format (not yet available in CLI args, use interactive mode)


COMPLETE EXAMPLE: Rules with Automation Format
-----------------------------------------------
python app/unified_rule_protocol_interactive_cli.py

Commands to enter:
  /automation on         # Enable automation format
  /scale 5.0            # Set 5 mmol scale
  /type rule            # Only show rules (not protocols)
  /k 3                  # Show top 3 results
  CCBr.c1ccccc1B(O)O>>CCc1ccccc1    # Your reaction

ALL AVAILABLE COMMANDS
----------------------
/k <int>                -> Set top_k (number of results)
/sim <float>            -> Set min_similarity (0.0-1.0)
/type <protocol|rule|all> -> Filter by source type
/automation on|off      -> Toggle automation format ⭐ NEW
/scale <float>          -> Set reaction scale in mmol ⭐ NEW
/details on|off         -> Toggle detailed output
/compact on|off         -> Compact one-line mode
/split on|off           -> Show top protocol + top rule
/stats                  -> Show index statistics
/load <id>              -> Load full source details
/show                   -> Display current settings
/help                   -> Show help
/exit or /quit          -> Exit
