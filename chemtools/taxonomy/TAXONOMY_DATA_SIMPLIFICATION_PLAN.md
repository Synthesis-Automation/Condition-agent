# Taxonomy Data Simplification Plan

## Goal

Reduce duplication in `chemtools/taxonomy/data` while keeping chemistry logic
canonical, explicit, and derivable from a small number of sources.

## Desired Layering

1. Primitive chemistry
   - `organic_groups.v1.3.json`
   - `substituent_fragments.v1.json`
   - `scaffold_motifs.v1.3.json`
2. Compound generation
   - `compound_generation_rules.v1.json`
3. Reaction logic
   - `group_logic.json`
   - `reaction_types.v4.0.json`
   - `synthons.v1.json`
4. Derived artifacts
   - `compound_logic.json`
   - `motif_scope_index.v1.json`
   - calculable feature JSONs

## Principles

- Identity lives in groups and motifs, not in featurizer heuristics.
- Compound motifs should be described as `A x B` chemistry when possible.
- Derived catalogs should be generated by code, not hand-expanded.
- Runtime consumers should load normalized payloads only through
  `chemtools.taxonomy.loader`.

## Completed In This Refactor

- Added loader-side support for compact `compound_logic` set definitions via
  `member_rules`.
- Centralized expanded motif-set access in
  `chemtools.taxonomy.loader.load_compound_logic_sets()`.
- Converted fully Cartesian `compound_logic` sets from explicit `members`
  lists to compact `A`/`B` rules.
- Converted the remaining partially Cartesian `compound_logic` sets to
  `member_rules` plus small `exclude` or explicit residual `members` lists.
- Removed direct `compound_logic.json` reads from key runtime consumers.

## Next Steps

1. Decide whether `hydrogenation_substrates` should remain an explicit
   chemistry basket or be split into smaller reaction-relevant families.
2. Move non-taxonomic heuristics out of `group_logic.json` and
   `featurizer_logic.json`.
3. Replace the large `include_pairs` block in
   `compound_generation_rules.v1.json` with rule-based generation plus
   exception overrides.
4. Mark `motif_scope_index` and calculable feature JSONs as generated assets
   and add a rebuild entrypoint.
5. Update taxonomy docs so they describe the normalized schema instead of the
   old fully expanded one.
