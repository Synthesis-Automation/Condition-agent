================================================================================
HOW TO USE
================================================================================

Python API:
-----------
from chemtools.recommend import recommend_from_reaction

result = recommend_from_reaction(
    reaction="Brc1ccccc1.Nc1ccccc1>>c1ccccc1Nc1ccccc1",
    k=50,
    relax={
        "catalyst_class": "Pd"  # Filter to Palladium only
    }
)

REST API:
---------
POST /api/v1/recommend
{
  "reaction": "Brc1ccccc1.Nc1ccccc1>>c1ccccc1Nc1ccccc1",
  "k": 50,
  "relax": {
    "catalyst_class": "Pd"
  }
}

================================================================================
USE CASES
================================================================================

1. Laboratory Constraints:
   "Our lab only has Pd catalysts available"
   → Use relax={"catalyst_class": "Pd"}

2. Green Chemistry:
   "Prefer Cu over Pd (cheaper, less toxic)"
   → Use relax={"catalyst_class": "Cu"}

3. Method Comparison:
   "Compare Buchwald-Hartwig (Pd) vs Ullmann (Cu)"
   → Run with both "Pd" and "Cu" filters

4. Reaction Optimization:
   "Test which metal gives best conditions"
   → Loop through ["Pd", "Cu", "Ni"]

================================================================================
HOW IT WORKS
================================================================================

Pre-filtering flow:

  Input Reaction
      ↓
  Family Detection (e.g., C_N_Coupling)
      ↓
  Load Dataset (15,967 reactions)
      ↓
  [CATALYST FILTER] → Filter to Pd (1,664 reactions)
      ↓
  Bin-based Candidate Pool (substrate matching)
      ↓
  DRFP Similarity Ranking
      ↓
  Top k Recommendations

Benefits:
  ✓ Reduces search space (15,967 → 1,664 for Pd)
  ✓ Faster recommendations
  ✓ Prevents catalyst cross-contamination
  ✓ More focused, chemically relevant results
